# Markeing-Analysis
마케팅 데이터 분석을 통한 비즈니스 전략 도출

마케팅에 데이터를 활용하는 이유는 비용감소 및 최적화 그리고 자동화라고 생각

## 분석방법
# 1. 측정값을 통한 기준
## 1.1. CLV 측정 : CLV란 고객생애가치로서 수식은 아래와 같다. = LTV
    - 고객가치 * 평균 고객 수명
    - 고객가치 : 평균구매가치 * 평균 구매 빈도
    - 평균 고객 수명 : 고객이 지속적으로 구매한 기간 / 총 고객 수

# 2. ARPU / ARPPU
## 2.1. ARPU : 총매출 / 전체 사용자 수 -> 서비스 전체 수익성
## 2.2. ARPPU : 총매출 / 결제 사용자 수 -> 결제 구조 / 가격 전략

# 3. RETENTION RATE
## 3.1. Retention : 고객이 이탈하지 않고 얼마나 오래 사용하는지
    - N일 후에도 남아있는 사용자 / 기준 사용자

# 4. Churn Rate 
## 4.1. 이탈율 : 이탈 사용자 / 전체 사용자

# 5. 장바구니 분석
## 5.1. 구매 직전 단계 병목 분석
    - 1. 총 구매 건수 계산
    - 2. '단일 상품 구매 건수' 계산
    - 3. 상품1, 상품2의 구매 건수 계산
    - 4. 상품1 구매건수와 상품 2 구매건수확인
    - 5. 총 구매건수 확인
    - 6. 지지도 계산 : 상품 조합 구매 건수/총구매 건수
    - 7. 신뢰도 계산 : 신뢰도 = (상품1 & 상품2 구매 건수) / (상품1 구매 건수)
    - 8. 여기서 뭘 보나
            지지도 ↑, 신뢰도 ↑
            → 묶음/추천/세트 구성 후보

            지지도 ↓, 신뢰도 ↑
            → 니치하지만 강한 연관

            지지도 ↑, 신뢰도 ↓
            → 단순 인기 상품

    - 연령/성별, 지역, 트래픽 소스, 방문페이지, 제품 등의 측정기준(dimension)을 통해서 사용자의 특성을 정의
